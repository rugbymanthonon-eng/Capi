# Capi — version 1.0

Capi est une PWA locale de suivi financier : dépenses, entrées, catégories personnalisables, EUR/CHF, statistiques par cycle, historique modifiable, archivage, sauvegarde/restauration et export CSV.

## Confidentialité

GitHub Pages héberge uniquement le code et les visuels. Les données financières restent dans IndexedDB sur l'appareil qui utilise Capi. Deux téléphones ont donc deux bases séparées.

## Publication

GitHub Pages doit publier la branche `main` depuis `/(root)`.
